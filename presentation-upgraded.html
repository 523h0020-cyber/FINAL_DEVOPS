1Phase 1: Terraform - Infrastructure as Code

🔧 Tại sao chọn Terraform?

  • Idempotent: Chạy nhiều lần không tạo duplicate resources
  • State Management: Terraform state tracking changes
  • Auto-generate SSH Key: RSA 4096-bit với permission 0400
# terraform/aws/main.tf - Auto SSH Key Generation
resource "tls_private_key" "generated" {
  count     = var.auto_generate_keypair ? 1 : 0
  algorithm = "RSA"
  rsa_bits  = 4096
}

resource "aws_key_pair" "generated" {
  count      = var.auto_generate_keypair ? 1 : 0
  key_name   = var.ssh_key_name
  public_key = tls_private_key.generated[0].public_key_openssh
}

resource "local_sensitive_file" "private_key" {
  count           = var.auto_generate_keypair ? 1 : 0
  filename        = var.keypair_output_path
  content         = tls_private_key.generated[0].private_key_pem
  file_permission = "0400"  # Secure permission for WSL
}

2Phase 2: Ansible - Configuration Management

📦 Ansible Playbooks Structure

01-bootstrap.yml
  • Update apt packages
  • Install Docker Engine
  • Configure Docker daemon
  • Add user to docker group
  • Enable Docker service
02-swarm.yml
  • Init Swarm on Manager
  • Get join token
  • Join Workers to cluster
  • Verify cluster state
03-traefik-letsencrypt.yml
  • Create traefik-public network
  • Deploy Traefik stack
  • Configure Let's Encrypt
  • Wait for convergence
# ansible/playbooks/02-swarm.yml
- name: Initialize Docker Swarm on manager
  hosts: manager
  become: true
  tasks:
    - name: Ensure manager is in swarm mode
      community.docker.docker_swarm:
        state: present
        advertise_addr: "{{ ansible_host }}"

    - name: Read swarm join tokens
      community.docker.docker_swarm_info:
      register: manager_swarm_info

- name: Join worker nodes to Docker Swarm
  hosts: workers
  become: true
  tasks:
    - name: Ensure worker is joined to swarm
      community.docker.docker_swarm:
        state: join
        join_token: "{{ hostvars[groups['manager'][0]].swarm_worker_join_token }}"
        remote_addrs:
          - "{{ hostvars[groups['manager'][0]].swarm_manager_endpoint }}:2377"

3Phase 3: Traefik - Reverse Proxy & SSL

🌐 Tại sao dùng Traefik?

  • Auto SSL: Let's Encrypt tự động renew certificates
  • Service Discovery: Tự động phát hiện Docker services qua labels
  • Zero Config: Không cần config file phức tạp
  • HTTP → HTTPS: Tự động redirect
# Traefik Stack với Let's Encrypt
services:
  traefik:
    image: "traefik:v3.0.4"
    command:
      - "--providers.docker=true"
      - "--providers.docker.swarmMode=true"
      - "--providers.docker.exposedByDefault=false"
      - "--entryPoints.web.address=:80"
      - "--entryPoints.websecure.address=:443"
      - "--certificatesResolvers.le.acme.email=admin@523h0020.site"
      - "--certificatesResolvers.le.acme.storage=/letsencrypt/acme.json"
      - "--certificatesResolvers.le.acme.httpChallenge=true"
      - "--certificatesResolvers.le.acme.httpChallenge.entryPoint=web"
    ports:
      - target: 80
        published: 80
        mode: host
      - target: 443
        published: 443
        mode: host
    volumes:
      - "/var/run/docker.sock:/var/run/docker.sock:ro"
      - "/opt/swarm/traefik/acme.json:/letsencrypt/acme.json"
    networks:
      - traefik-public
    deploy:
      placement:
        constraints:
          - "node.role == manager"
      labels:
        - "traefik.enable=true"
        - "traefik.http.middlewares.https-redirect.redirectscheme.scheme=https"

🛡️ DevSecOps: Trivy Security Scanning

Bắt buộc PASS trước khi deploy

# .github/workflows/ci-cd.yml - Trivy Filesystem Scan
- name: Trivy filesystem scan (fail on High/Critical)
  uses: aquasecurity/trivy-action@master
  with:
    scan-type: fs
    scan-ref: "${{ env.APP_DIR }}"
    severity: "HIGH,CRITICAL"
    ignore-unfixed: true
    exit-code: "1"  # ← Pipeline FAIL nếu phát hiện lỗ hổng

# Trivy Image Scan (sau khi build)
- name: Trivy image scan (fail on High/Critical)
  uses: aquasecurity/trivy-action@master
  with:
    scan-type: image
    image-ref: "${{ env.DOCKER_IMAGE }}:scan-${{ github.sha }}"
    severity: "HIGH,CRITICAL"
    ignore-unfixed: true
    exit-code: "1"
⚠️ Security Policy
  • HIGH/CRITICAL vulnerabilities: Pipeline bị block, không cho deploy
  • MEDIUM/LOW: Warning only, vẫn deploy được
  • ignore-unfixed: Bỏ qua lỗi chưa có patch (tránh false positive)

📦 Docker Image Tagging Strategy

Semantic Versioning + SHA Tags

# Prepare semantic tags
- name: Prepare semantic tags
  id: prep_tags
  shell: bash
  run: |
    SHA_TAG="sha-${GITHUB_SHA::7}"
    SEMVER_TAG="v1.0.${GITHUB_RUN_NUMBER}"
    echo "sha_tag=${SHA_TAG}" >> "$GITHUB_OUTPUT"
    echo "semver_tag=${SEMVER_TAG}" >> "$GITHUB_OUTPUT"

# Build and push semantic tags (NO latest tag)
- name: Build and push semantic tags
  uses: docker/build-push-action@v6
  with:
    context: ${{ env.APP_DIR }}
    push: true
    tags: |
      ${{ env.DOCKER_IMAGE }}:${{ steps.prep_tags.outputs.sha_tag }}
      ${{ env.DOCKER_IMAGE }}:${{ steps.prep_tags.outputs.semver_tag }}
Tag Type Example Purpose
SHA Tag sha-a1b2c3d Traceability - Biết chính xác commit nào được deploy
Semver Tag v1.0.42 Auto-increment version (dựa vào GITHUB_RUN_NUMBER)
Git Release Tag v2.0.0 Manual release tag (chỉ khi push tag v*.*.*)

⚠️ Best Practice: KHÔNG dùng "latest" tag trong production (không rollback được)

🚀 Zero-Downtime Deployment Strategy

Docker Swarm Rolling Update

# swarm-stack.yml - App Service Configuration
services:
  app:
    image: ${DOCKER_IMAGE}:${APP_VERSION}
    deploy:
      replicas: 3  # ← 3 replicas để đảm bảo HA
      update_config:
        parallelism: 1      # Update từng container một
        delay: 10s          # Đợi 10s giữa mỗi update
        order: start-first  # ← Start new container TRƯỚC khi stop old
      restart_policy:
        condition: on-failure
      labels:
        - "traefik.enable=true"
        - "traefik.http.routers.app.rule=Host(`${DOMAIN_NAME}`)"
        - "traefik.http.routers.app.entrypoints=websecure"
        - "traefik.http.routers.app.tls.certresolver=le"
        - "traefik.http.services.app.loadbalancer.server.port=3000"
📊 Rolling Update Flow
  1. Start new container (v1.0.2)
  2. Wait for health check pass
  3. Traefik route traffic to new
  4. Stop old container (v1.0.1)
  5. Repeat for next replica
✅ Benefits
  • Zero Downtime: Luôn có container serving
  • Auto Rollback: Nếu new version fail, Swarm tự rollback
  • Gradual Rollout: Phát hiện lỗi sớm
