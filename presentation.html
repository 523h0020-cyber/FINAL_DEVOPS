Nguyên tắc Phân tầng

  • Tier 2: Business Logic. Stateless Node.js APIs (Auto Scale-out).
  • Tier 3: Database. MongoDB lưu giữ cơ sở dữ liệu.
  • Tier 4: Observability. Dashboard giám sát Prometheus + Grafana đứng ngoài luồng dữ liệu chính.

3. Infrastructure as Code (Terraform)

Đảm bảo Idempotency
  • Tính đồng nhất: Với tệp .tfstate, Terraform chỉ sửa khoảng trống so với file mô tả, chạy bao lần vẫn duy trì 1 trạng thái.
  • Cố định Entrypoint: Tránh IP loạn nhịp sau mỗi lần Start/Stop, ta sử dụng aws_eip (Elastic IP) ghim cứng lối vào Swarm Manager.

# terraform/aws/main.tf
# Chốt IP Tĩnh (Elastic IP) cho Swarm Manager
resource "aws_eip" "manager_eip" {
  instance = aws_instance.manager.id
  domain   = "vpc"

  tags = {
    Name = "swarm-manager-eip"
    Role = "Manager"
  }
}
Cấu hình cố định Cổng kết nối Public

Zero-Trust Topology (Security Groups)

Theo nguyên lý phân quyền tinh gọn, ta đóng mọi Port thừa. Swarm chỉ bóc tách luồng giao tiếp nội bộ thông qua port riêng của Manager và Worker.

flowchart TD A(Client) -->|TCP 80/443| B[Manager SG Traefik] B -->|TCP 2377 Cluster| C[Worker SGs] B -.->|Drop chặn đứng| D(TCP 27017 Public) 

# terraform/aws/main.tf
resource "aws_security_group" "swarm_sg" {
  name        = "swarm-security-group"
  
  # Nội bộ VPC: Quản trị cluster Swarm Node
  ingress {
    from_port   = 2377
    to_port     = 2377
    protocol    = "tcp"
    cidr_blocks = [var.vpc_cidr]
  }

  # Public: Mở đường Traefik cho HTTP/HTTPS
  ingress {
    from_port   = 443 
    to_port     = 443
    protocol    = "tcp"
    cidr_blocks = ["0.0.0.0/0"]
  }
}

4. Cấu hình Cụm (Ansible)

Kiến trúc Agentless Deployment
Sức mạnh của Ansible nằm ở việc không cần cài đặt thêm app ẩn nào trên EC2, tất cả qua SSH.

  1. Pre-task: Chuẩn hóa môi trường, gói cơ bản.
  2. Docker-engine: Thêm Repo và tải tự động.
  3. Swarm-Init: Tạo Token kết nối Nodes.

Sự Tinh Gọn Kỹ Thuật (Idempotent Run)

Lệnh Swarm Init sẽ văng lỗi Crash (Exit Code 1) nếu node đã bật. Ta thiết lập cờ kiểm tra LocalNodeState để bộ cài Ansible trở nên hoàn hảo không lỗi vặt.


# playbooks/02-swarm.yml
- name: Kiểm tra trạng thái Swarm Node
  command: docker info --format '{{{{ .Swarm.LocalNodeState }}}}'
  register: swarm_status
  changed_when: false

- name: Ra lệnh khởi tạo Manager (Nếu chưa)
  command: docker swarm init --advertise-addr {{{{ ansible_host }}}}
  when: swarm_status.stdout != 'active'

Quy trình Quét Lỗ Hổng Nhúng Gọn (Shift-Left)

Bước phòng thủ Trivy ngăn chặn luồng CI lại ngay nếu Base image hoặc NPM modules dính lỗ hổng hệ trọng.

Tham số exit-code: 1 giúp đóng cổng hoàn toàn rủi ro trước khi ra Prod.


# .github/workflows/ci.yml
- name: Run Trivy Scanner
  uses: aquasecurity/trivy-action@master
  with:
    image-ref: '${{{{ secrets.DOCKER_USER }}}}/app'
    format: 'table'
    exit-code: '1' # LÊN PROD PHẢI SẠCH LỖI
    ignore-unfixed: true
    vuln-type: 'os,library'
    severity: 'CRITICAL,HIGH'

Luồng CD - Continuous Deployment

Cập nhật ứng dụng tự động bằng Key SSH từ Github sang Swarm Manager.

Swarm duy trì stack deploy giúp dàn trải Container đều qua Worker một cách mượt mà, Zero-downtime.


- name: SSH Deploy to Swarm
  uses: appleboy/ssh-action@master
  with:
    host: ${{{{ secrets.DEPLOY_HOST }}}}
    username: ubuntu
    key: ${{{{ secrets.SSH_PRIVATE_KEY }}}}
    script: |
      docker pull ${{{{ secrets.DOCKER_USER }}}}/app:main
      docker stack deploy -c /home/ubuntu/swarm-stack.yml tier4

6. Traefik Routing & Observability

Hai thiết kế cuối cùng định hình khối Tier chuyên nghiệp:

  • Traefik Proxy: Nhận diện dịch vụ tự động chỉ từ Docker qua Labels, lấy SSL Let's Encrypt ngầm (Automated TLS). Thay thế hoàn toàn rắc rối của Nginx.
  • Prometheus & Grafana: Kéo thông số về lưu tại DB Chuỗi thời gian và vẽ tổng quan Metrics tập trung, quản lý sức khỏe System.

Labels Tự Sinh SSL (Service Discovery)

Chỉ cần khai báo 4 dòng, Traefik sẽ lập tức bắt tín hiệu App, phát hành domain, ép kết nối qua HTTPS mà không cần cấu hình file rời rạc. 

# Phân đoạn App trong swarm-stack.yml
deploy:
  labels:
    - "traefik.enable=true"
    - "traefik.http.routers.app.rule=Host(`demo.aws-tech.com`)"
    - "traefik.http.routers.app.entrypoints=websecure"
    - "traefik.http.routers.app.tls.certresolver=letsencrypt"

7. Kịch bản Thực Trọng (Live Demo)

Giai đoạn 1: Auto-Deploy Flow
  1. Bật Dashboard App (Giao diện cũ).
  2. Developer git push thay đổi Navbar hiển thị.
  3. Trivy Scan hiển thị Xanh ngắt.
  4. Pipiline Deploy qua SSH, load F5 Web chuyển mới hoàn toàn, giữ luồng request không đứt gãy.
Giai đoạn 2: Chaos & Self-Healing
  1. Bật Grafana xem RAM hệ thống.
  2. Log vào Worker hạ gục trực tiếp App Container (docker rm -f).
  3. Swarm nhận diện thiều hụt 1 mảnh Replica lập tức đắp lệnh khởi chạy container mới bù lỗ hổng. (Self-heal cực lẹ).
